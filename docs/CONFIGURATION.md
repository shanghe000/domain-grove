# 配置

工作台仅在本机回环地址提供服务。运行示例使用本机身份和独立 SQLite 目录。

| 环境变量 | 用途 |
| --- | --- |
| `GO_SERVER_ADDR` | 本机回环监听地址，默认为 `127.0.0.1:8080`。 |
| `DATA_DIR` | 图谱数据库与项目空间数据根目录。 |
| `PUBLIC_URL` | 可选的本机回环 HTTP(S) 来源，用于校验浏览器写操作。 |
| `INDEX_ALLOW_DEV_REVIEW` | 设为 `true` 后启用本机审核和知识空间管理，默认以只读模式浏览。 |
| `MCP_API_TOKEN` / `MCP_SUBMIT_TOKEN` | 默认项目的读取与提交凭据。命名项目可在空间设置中分别签发。 |
| `LLM_API_KEY` | 模型服务密钥。按需设置。 |
| `LLM_BASE_URL` / `LLM_MODEL` | 模型端点和模型名。默认使用 DeepSeek 兼容接口。 |

如需在本机使用 HTTPS，同时设置 `GO_TLS_CERT_FILE` 与 `GO_TLS_KEY_FILE`。

## 外部模型

开启模型后，建模请求携带指令、发布图谱及已提供的资料定位。只提交允许发送的数据。办完审核前，模型补丁停留在草案或待审队列。模型请求协议覆盖本地替身验证。
